# macaroList — Privacy Policy

Public policy site: https://featureike.github.io/

- Japanese: `index.html`
- English: `en/index.html`
- Shared styles: `style.css`
- Hosting: GitHub Pages, `main` branch, repository root (`/`).

## Edit in GitHub

1. Open the HTML file for the language to update.
2. Click the pencil (Edit this file), update the relevant text, and update the visible revision date and `datetime` value.
3. Keep the Japanese and English policies consistent.
4. Commit the changes to `main`.
5. Wait for the Pages deployment to finish and reload both public pages.

## Edit locally

Clone this repository, edit the same files, commit, and push to `main`.
To preview locally, run `python3 -m http.server 8765` in the repository and open http://localhost:8765/.

## Publication settings

In repository **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**. Keep HTTPS enabled.

This repository contains only public website files. Do not add credentials, support submissions, application databases, or private application source code.
